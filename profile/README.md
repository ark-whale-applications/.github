## Pointwise

### Collaborative GitHub issue estimation with your team and GitHub Copilot

Pointwise brings planning-poker style estimation directly to GitHub issues. Teams estimate together, then use GitHub Copilot for an independent advisory assessment based on the issue and relevant repository context.

**Estimate together. Review with Copilot. Stay close to the code.**

### What it does

- Select a GitHub repository and issue.
- Invite repository contributors into a shared estimation session.
- Collect team estimates using a Fibonacci scale.
- Ask GitHub Copilot to review the task using issue and repository context.
- Compare the team's estimate with Copilot's advisory estimate and assessment.
- Copy or export the resulting review for use in planning and refinement.
